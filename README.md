# ريال بريال — RiyalByRiyal

**«كل ريال محسوب» — Every riyal counted**

## بالعربي
هذا المستودع مخصص لنشر إصدارات تطبيق «ريال بريال» لأندرويد (ملفات APK).
كل تحديث جديد ينزل هنا في قسم **Releases**، والتطبيق يتحقق منه ويثبّته فوق النسخة السابقة بدون ما تضيع بياناتك.

لتحميل التطبيق ومعرفة المزيد: https://riyalbyriyal.sites.tab.bot/

## English
This repository hosts the Android APK releases of **RiyalByRiyal** (ريال بريال), a personal finance app.
New versions are published under **Releases**; the app checks here for updates and installs them over the previous version, keeping your data.

Download and details: https://riyalbyriyal.sites.tab.bot/
